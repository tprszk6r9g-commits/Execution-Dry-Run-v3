Rustee NVDA Trade Executor

This standalone performs a manually approved, real mainnet NVDA purchase using Rustee's generic Vault TBA as the executor and sends the purchased NVDA directly to the Trading TBA. It does not enable autonomous trading or change the paused StockTokenRegistry.

Execution model

Owner wallet → Vault TBA → Uniswap SwapRouter02 → NVDA → Trading TBA. Each state-changing action requires your wallet confirmation. The final trade button stays disabled until an eth_call simulation of the exact transaction succeeds.

This deliberately bypasses the currently paused restricted Trading-TBA execution policy for this one manual test. It does not unpause or configure that policy.
