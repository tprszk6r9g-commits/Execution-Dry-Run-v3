# Rustee Broker v3.3 — Strategy Lab + Paper Twin

Built directly on v3.2 Supervised Autopilot and the verified v3.1.2 mobile wallet handoff.

## Added
- Strategy Lab tab.
- Deterministic strategy designer for price-threshold entries with take-profit, stop-loss and optional maximum-hold exits.
- Local market recorder for strategy tickers while Rustee is open.
- CSV/JSON historical price import and JSON export.
- Deterministic historical replay/backtester with configurable slippage and fee assumptions.
- Metrics: ending equity, total return, max drawdown, trade count, win rate, profit factor, average win/loss, exposure and open-position state.
- Paper Twin mode using the same replay engine against observations recorded after Paper mode starts.
- Strategy Tournament comparison/ranking.
- Explicit Draft → Paper → Armed lifecycle.
- Promotion gate requires Paper stage plus a backtest of at least 10 samples.
- Promotion creates supervised Autopilot entry / take-profit / stop-loss rules; it does not enable Autopilot or broadcast a transaction.
- Demotion removes only the rules generated by that strategy.

## Execution boundary
Strategy Lab contains no autonomous wallet/broadcast path. It never calls `eth_sendTransaction`, never opens the wallet, and never invokes the real execution function. Real trades remain behind v3.1.2's user-gesture wallet handoff.

## Data note
Backtests use only locally recorded or explicitly imported price samples. Rustee does not fabricate missing historical prices. Results are scenario replays, not forecasts.

## Stability
No Solidity source, Foundry configuration, or contract tests were modified.
