# Rustee Broker v3.6B.1 — GitHub Keep-Only Package

This package contains the project files intended to be kept in the GitHub repository.

## Keep
- assets/
- data/
- lib/
- script/
- scripts/
- src/
- test/
- tools/
- .github/workflows/
- foundry.toml
- index.html
- sw.js
- README.md
- project documentation and configuration files

## Intentionally removed
- out/ — generated Foundry compiler artifacts
- cache/ — generated Foundry cache
- broadcast/ — generated deployment transaction output, if present
- evidence/ — local compile/test evidence bundle
- *.log — local build/test logs

The Solidity source, Foundry tests, deployment script, forge-std library, and both GitHub workflows are retained.
