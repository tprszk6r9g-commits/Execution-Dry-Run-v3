# Rustee Broker AIO v3.0.0 — Integration Release

## Added

- Unified Rustee branding and 384×384 Broker artwork in the Command Center.
- New **NFT + Identity** tab.
- Runtime ERC-6551 Broker NFT resolution and cross-check.
- Four-TBA identity overview.
- Embedded exact on-chain metadata payload from RusteeBroker1.
- Metadata preflight, simulation, write, verify, and optional irreversible freeze flow.
- Security allowlist extension limited to the correctly resolved Rustee Broker NFT.
- Integrated GitHub workflow metadata-payload validation.
- Rollback copies of both source apps.

## Preserved

- v2.8.12 interrupted-sell recovery.
- SELL proceeds choice: WETH in Vault or native ETH via a separate unwrap transaction.
- Existing wallet handoff hardening and EIP-6963 wallet discovery.
- Portfolio, trade, history/P&L, Account Center, Move Assets, Operations, Security, Production, and Evidence/Replay panes.
- Existing Foundry contracts/tests and data update scripts.

## Deliberately not changed

The established buy/sell transaction construction and recovery sequence was not rewritten as part of the AIO merge. The integration is additive around the stable execution core.
